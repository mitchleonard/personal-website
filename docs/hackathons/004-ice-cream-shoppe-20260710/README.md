# Hackathon #004 — Ice Cream Shoppe

## Pitch

My ratings, recommendations, and homemade pints—all served from one digital shoppe.

## Context

Since 2020, Mitch has tracked roughly 150 ice cream ratings from around the country and locally. The list lives in a personal Apple Note while the photos and their date and location metadata live in iPhone albums, leaving no easy public collection to share when someone asks for recommendations.

## Definition of done

The Ice Cream Shoppe is live on mitchleonard.com, visitors can browse and sort real ratings, and a simple repeatable workflow can ingest new ratings without becoming a barrier to continued tracking.

## Build parameters

- Started: July 10, 2026 at 9:44 PM CDT
- Budget: 90 minutes
- Tags: Hackathon, Data Visualization, Digital Archive
- Model experiment: document how GPT-5.6 performs across speed, autonomy, design judgment, implementation quality, and corrections required

## Deliverables

- Persistent Ice Cream Mode across the website
- A memorable Ice Cream Shoppe destination
- Sortable ratings by recency and score
- Map-ready location exploration
- A distinct Made by Mitch collection
- A low-friction ongoing ingestion workflow
- Milestone evidence suitable for the project case study
